## 📂 Projects Included

### 1️⃣ Stock Portfolio Dashboard 📈  
**Goal:** Download and visualize stock data using `yfinance`, `pandas`, `matplotlib`, and `seaborn`.

**Key features:**
- Fetches real stock data from Yahoo Finance  
- Calculates daily returns  
- Plots stock prices and normalized (indexed) performance for easy comparison  
- Works with one or multiple tickers  

**Skills demonstrated:**  
`Python`, `Financial Data Visualization`, `Pandas`, `Matplotlib`, `Seaborn`, `Git`
